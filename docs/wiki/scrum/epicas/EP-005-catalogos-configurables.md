# EP-005 — Catálogos configurables

## Objetivo

Permitir que ADMIN administre EPS y planes de EPS mediante CRUD sin borrado físico, cerrando el alcance que EP-001 había dejado pendiente.

## HU

- [[HU-023-crud-de-eps-y-planes]]

## Reglas

No se permite borrado físico de EPS ni planes; se usa activación/desactivación. Un plan bajo una EPS inactiva deja de ofrecerse en el catálogo público y en el registro.
